Instrucciones para la Eliminación de Datos

Cumplimiento de las normas de Meta para Jona Logic APIS

En Jona Logic APIS, valoramos tu privacidad y te otorgamos el control total sobre los datos que compartes con nosotros. De acuerdo con las políticas de Meta (Facebook) sobre aplicaciones y sitios web, proporcionamos esta página para que puedas solicitar de forma transparente y sencilla la eliminación de tu información de nuestros sistemas.

Importante: Al eliminar tus datos, perderás el acceso a las funciones personalizadas de nuestra aplicación asociadas a tu cuenta de Facebook y esta acción no se puede deshacer.

Pasos para revocar el acceso y eliminar tus datos a través de Facebook

Si utilizaste el inicio de sesión de Facebook en nuestra aplicación, puedes eliminar las actividades de tu app siguiendo estas instrucciones oficiales:

  1. Ve a la configuración de tu perfil de Facebook en el siguiente enlace: Configuración de Apps y sitios web. (O navega de forma manual desde tu perfil a: Configuración y privacidad > Configuración > Apps y sitios web).
  2. Busca y localiza la aplicación llamada Jona Logic APIS en la lista de aplicaciones activas.
  3. Haz clic en el botón Eliminar situado junto al nombre de la aplicación.
  4. Se abrirá una ventana emergente. Marca la casilla que te permite eliminar también el historial de publicaciones o interacciones (si aplica) y confirma haciendo clic de nuevo en Eliminar.
  5. ¡Listo! Facebook notificará a nuestro sistema y se revocará inmediatamente el acceso.

Solicitud de eliminación manual (Base de datos interna)

Si deseas asegurarte de que cualquier registro residual o información de perfil almacenada en nuestros servidores sea completamente borrada de forma manual, sigue este paso:

  • Envía un mensaje de correo electrónico a nuestro administrador a la dirección: jonathanvegagomez21@gmail.com.
  • Coloca como asunto del mensaje: "Solicitud de Eliminación de Datos - Jona Logic APIS".
  • En el cuerpo del mensaje, indícanos tu nombre completo o el ID de usuario con el que te registraste. Procesaremos la solicitud y eliminaremos de forma definitiva tus datos de nuestra base de datos en un plazo no mayor a **72 horas**.
